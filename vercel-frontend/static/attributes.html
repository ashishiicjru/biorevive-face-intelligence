About the gender estimate. It is a binary guess from appearance by a small 2015 network trained on web photos. It is error-prone (it misjudged a test photo of a woman as male), cannot represent anyone's gender identity, and is less reliable for some groups. Never use it to make decisions about people.
Train your own texture models

The app can learn age / gender from texture features only (LBP, Gabor, edge density, skin colour) with a NumPy ridge / logistic model — you provide labelled faces such as UTKFace:

python programs/train_texture_model.py --task age --data path/to/UTKFace

python programs/train_texture_model.py --task gender --data path/to/UTKFace

texture-age model: …texture-gender model: …

Hand-crafted texture features are far weaker than the CNNs; the trainer reports held-out error next to a trivial baseline so you can see what it really learned.
